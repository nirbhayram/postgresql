# PostgreSQL Handbook

An interactive single-page reference for PostgreSQL, built with Next.js, React, and Tailwind CSS.

**Live:** [https://postgresql-brown.vercel.app/](https://postgresql-brown.vercel.app/)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.

## Commands

```bash
npm run dev      # development server
npm run build    # production build
npm run lint     # ESLint
npx tsc --noEmit # type-check
```

## Deploy

Deployed on [Vercel](https://vercel.com). Pushes to `main` trigger automatic deployments.
